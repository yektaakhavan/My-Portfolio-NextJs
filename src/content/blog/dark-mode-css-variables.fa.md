حالت تیره شبیه یک کلید ساده است، ولی بیشتر کار در نام‌گذاری رنگ‌هاست. این ساختاری است که استفاده می‌کنم، به‌همراه دو جزئیاتی که حس حرفه‌ای می‌دهند: بدون پرش سفید هنگام بارگذاری، و کنتراست خوانا در هر دو تم.

## رنگ‌ها را با نقش نام‌گذاری کنید، نه با درجه

به‌جای `gray-900` یا `purple-500`، رنگ‌ها را بر اساس کاری که می‌کنند تعریف کنید: `canvas` برای پس‌زمینه‌ی صفحه، `surface` برای کارت‌ها، `fg` برای متن، `muted` برای متن فرعی و `accent` برای لینک‌ها و دکمه‌ها. هر نقش برای هر تم یک مقدار دارد:

```css
:root,
:root[data-theme="dark"] {
  --c-canvas: #140d24;
  --c-fg: #f3eefb;
}
:root[data-theme="light"] {
  --c-canvas: #faf7ff;
  --c-fg: #1c1430;
}
```

در Tailwind نسخه‌ی ۴ یک بار این متغیرها را به‌صورت utility در دسترس می‌گذارید (`bg-canvas`، `text-fg`) و هر کامپوننت بدون حتی یک پیشوند `dark:` در هر دو تم درست کار می‌کند.

## به سیستم احترام بگذارید، انتخاب را به خاطر بسپارید

اولین بازدید باید از سیستم‌عامل پیروی کند (`prefers-color-scheme`). بعد از اینکه بازدیدکننده دکمه را زد، انتخاب او مقدم است و در `localStorage` ذخیره می‌شود.

## مشکل پرش

اگر تم بعد از بارگذاری React اعمال شود، بازدیدکننده‌های حالت تیره اول یک پرش سفید می‌بینند. راه‌حل یک اسکریپت inline کوچک در `<head>` است که پیش از اولین رسم صفحه اجرا می‌شود:

```js
(function () {
  try {
    var t = localStorage.getItem("theme");
    if (t !== "light" && t !== "dark") {
      t = matchMedia("(prefers-color-scheme: light)").matches ? "light" : "dark";
    }
    document.documentElement.dataset.theme = t;
  } catch (e) {
    document.documentElement.dataset.theme = "dark";
  }
})();
```

## کنتراست را فراموش نکنید

پالتی که در حالت تیره عالی به نظر می‌رسد ممکن است در حالت روشن مردود شود. رنگ‌هایی که به‌عنوان *پس‌زمینه‌ی پرشده* خوب‌اند، اغلب به‌عنوان *متن* بیش‌ازحد کم‌رنگ‌اند. من قبل از اینکه به چشمم اعتماد کنم، هر جفت متن و پس‌زمینه را در هر دو تم با یک اسکریپت کوچک و بر اساس نسبت‌های WCAG می‌سنجم (۴٫۵ به ۱ برای متن و ۳ به ۱ برای اجزای رابط).

## فهرست سریع

- رنگ‌ها با نقش نام‌گذاری شوند، یک مقدار برای هر تم
- پیش‌فرض از سیستم، و انتخاب به خاطر سپرده شود
- اسکریپت inline پیش از اولین رسم صفحه
- کلید تم یک دکمه‌ی واقعی باشد که برچسبش بگوید چه می‌کند («تغییر به حالت روشن»)
- کنتراست در هر دو تم بررسی شود
